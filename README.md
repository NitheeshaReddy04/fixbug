# 📖 Overview

FixBug is a full-stack application designed to provide a seamless and responsive user experience while following modern development practices. The project focuses on clean architecture, scalability, and maintainable code.

Whether you're exploring the project or contributing to it, the codebase is organized for readability and future enhancements.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/NitheeshaReddy04/fixbug.git
```

Go into the project

```bash
cd fixbug
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
